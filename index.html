TypeScript

There's no separate npm package here — the core highcharts package ships its own bundled .d.ts declarations (since Highcharts 7), so there's no peer-dependency table to publish. Two things worth knowing instead:
TopicDetail
Minimum setupAny recent TypeScript version works with editor autocomplete once highcharts is installed via npm (CDN-only usage has no type declarations available).
TypeScript 5+Requires setting "moduleResolution": "bundler" in tsconfig.json for the declarations to resolve correctly.
Source: Highcharts TypeScript declarations docs

Python

Official toolkit is Highcharts for Python: pip install highcharts-core (plus highcharts-stock, highcharts-maps, highcharts-gantt as extensions). This wraps the JS library rather than declaring a formal dependency on it, so compatibility is a stated floor, not an npm-style peer range.
